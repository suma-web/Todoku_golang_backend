# 負荷試験スクリプト

k6でHTTP/API負荷とブラウザログインを確認します。ファイル名のVUは仮想ユーザー数です。

| ファイル | 試験内容 | 実行時間 |
| --- | --- | --- |
| `frontend-http-smoke-5vu.js` | 5 VUでトップページのHTTP疎通・応答時間を測定 | 30秒 |
| `api-auth-session-10vu.js` | 10 VUでセッションを保持し、5回操作ごとにログアウト | 3分 |
| `api-normal-load-645vu.js` | 最大645 VUまで段階的に増減してAPIを測定 | ステージ合計36分 |
| `api-emergency-spike-645vu.js` | 1秒で645 VUへ増加、5分維持、1分で0へ減少 | ステージ合計6分1秒 |
| `browser-login-100vu.js` | Chromiumで100 VUが各1回ログインし、URL判定・LCP・FCPを測定 | 最大2分 |

## 準備と実行

HTTP試験にはk6、ブラウザ試験にはk6とChromiumが必要です。
`frontend-http-smoke-5vu.js`以外は、このフォルダの`users.json`を読み込みます。
ファイル形式は`[{"email":"テスト用メールアドレス","password":"テスト用パスワード"}]`です。
認証情報はGit管理対象外です。VU番号に応じてアカウントを割り当て、不足すると同じアカウントを再利用します。
645人の異なる利用者を模擬する場合は、異なる645アカウントを用意してください。

既定の接続先はAWS上の環境です。実行時は対象を明示してください。
以下は実行方法の例であり、CIから負荷試験を自動実行する設定はありません。

```sh
k6 run -e API_URL=https://YOUR_TEST_API load-test/api-emergency-spike-645vu.js
k6 run -e BASE_URL=https://YOUR_TEST_FRONTEND load-test/frontend-http-smoke-5vu.js
```

## 現在の測定条件

- 通常・緊急API試験は毎反復でログインし、ユーザー情報・タイムラインを取得します。Cookieは保持しますが、ログインの省略は行いません。
- 通常・緊急API試験はタイムライン取得を5回試行するとログアウトします。失敗した取得も試行回数に含まれます。
- 緊急試験は1秒でVUを増やす設定であり、全リクエストの厳密な同時送信は保証しません。645 VUは毎秒645リクエストを意味しません。
- 認証セッション試験は未ログイン時のみログインします。ログアウト後の期待する401もHTTP失敗率に算入されるため、checksが成功してもHTTP失敗率の基準を満たさない場合があります。
- 認証セッション試験はCookieやレスポンス本文をログに出力します。実行ログの公開・共有前に認証情報を除去してください。
- ブラウザ試験は固定待機後のURLでログインを判定し、認証済みデータの表示までは検証しません。
- API試験の合格基準や待機時間を含む実行処理は維持しています。ファイル名・コメントの整理は過去の測定結果の再現を保証するものではありません。
